# RGB MoCap 使用指南

本页按上游使用指南的顺序介绍本次更新的章节。其他章节见[完整英文使用指南](USER_GUIDE.md)，本 fork 独有的功能见 [Fork 指南](FORK_GUIDE.md)。

## 安装

### 可选的 SAM 3.1 人物追踪器

完成基础安装后，关闭 RGB MoCap 并运行 `Setup_SAM31.cmd`。它复用 ExMR 的 Python 和 CUDA 环境，需要支持原生 bfloat16 的 NVIDIA CUDA 显卡。重新打开软件，选择 ExMR、FlowHMR 或 GVHMR，在**查找人物**旁选择 **SAM 3.1**，再从**模型管理器**下载或导入支持的权重。安装和更新时需单独运行该脚本。SAM 3.1 的显存占用高于默认追踪器。详见 [SAM 3.1 中文指南](models/SAM31.zh-CN.md)。

## Blender 骨骼串流

1. 下载 [RGB MoCap Bone Stream ZIP](../blender_addon/rgbmocap_bone_stream.zip?raw=1)。在 **Blender 4.5 或更新版本**打开 **Edit > Preferences > Add-ons**。曾安装过早期单文件版本时，先移除旧版。
2. 从 **Add-ons** 右上角菜单选择 **Install from Disk**，选中完整 ZIP 并启用 **RGB MoCap Bone Stream**。
3. 在 RGB MoCap 打开已有动捕结果的项目，在左侧**串流**页将目标从**无**切换到 **Blender**，勾选要发送的人物。串流勾选与**人物**页的可见性分别控制。
4. 在 Blender 的 3D 视口按 **N**，打开 **RGB MoCap > RGB MoCap Bone Stream**，点击 **Connect**。默认端口为 `49168`。在 RGB MoCap 播放或拖动时间轴时，Blender 中的骨架会跟随动作和根位移。串流绑定到连接时的 Blender 场景与视图层，切回即可继续预览。

串流在本机传输已处理的离线源人物骨骼，实时预览时不创建关键帧。取消勾选人物会隐藏对应骨架。**Disconnect** 会保留现有对象，重连同一人物和静止骨架时会复用骨架及其修改。将目标切回**无**可关闭串流。需要带蒙皮或材质的重定向角色时，可导出该角色的 FBX。

在 Blender 的 **Object Mode** 中，**Clean** 可检查并移除当前场景中未使用的串流骨架。仍勾选的人物、已烘焙或被其他对象引用的骨架会保留。移除前由 Blender 确认。

在 Blender 的 **Object Mode** 选择正在接收串流的骨架，点击 **Bake**。只有一套串流骨架时，插件会自动选用它。烘焙保存该演员整段已录制的动作和根运动，使用 Blender 当前场景的帧率。分段之间的空档会保持上一姿势，直到下一段开始。单次最多烘焙 **36,000 个时间轴帧**。

完成后，这套骨架会成为普通 Blender 对象，其他已勾选的人物继续串流。保存 `.blend` 即可保留 Action。请搭配相同版本的 RGB MoCap 和串流插件使用。

## FBX 与 Blender

通过**文件 > 导出…**导出当前选中的源人物动作。可选 FBX、BVH 或便携 Blender 工程。每个勾选的人物或动作片段会分别导出。以下选项默认关闭，重定向角色的导出使用自己的设置。

| 选项 | 作用 |
| --- | --- |
| **FBX 兼容模式（Maya）** | 由随附的 Blender 在后台写入 FBX，保留源骨架的静止姿势和动画，可用于 Maya 或 Blender。 |
| **导出时移到原点** | 将每位人物的首帧根节点分别移到水平原点（X=0、Z=0），保留高度、朝向和后续位移。同一人物的多个导出片段共用这次偏移。双人互动需要保留相对站位时，保持关闭。 |
| **对称静止姿态** | 将 SMPL 源骨架左右对应骨段的参考长度和方向做成对称。保留动作时序和旋转，手脚落点可能改变，接触也不会重新求解。 |
| **在动作前添加 T 姿势** | 在原动作前插入一帧参考姿势。原动作顺延一帧，原本的骨架绑定姿势保留。 |

**导出时移到原点**和**对称静止姿态**用于支持的源骨架 FBX/BVH 导出。SMPL 的 BVH 可选 **通用 / Blender** 或 **3ds Max Biped** 配置。

### 预览视频

通过**文件 > 导出预览…**保存 MP4。左侧是选中的输入相机，右侧是当前 3D 视口。导出采用当前裁剪区间、可见人物和视口设置，有源音频时一并保存。此功能适用于离线项目。

### 便携 Blender 工程

对于 SMPL 动作，在**文件 > 导出…**中选择 **Blender 工程与视频 (.blend)**。每个导出人物或动作片段各有一个新文件夹，包含工程、同步视频和相机报告。用 Blender 4.5 或更新版本打开，按数字键盘 **0** 切到源相机视角。移动工程时请保留整个文件夹。已保存的相机跟踪可随工程导出，相机选项只影响导出的相机。

### GEM-X SOMA Blender 工程

FBX 和 BVH 包含 30 fps 的 SOMA Native77 骨架动作，均可在导出时移到原点，或在动作前添加一帧原生静止姿势。BVH 使用通用 / Blender 配置。

便携 Blender 工程在 **SOMA Motion** 场景提供可编辑的 77 骨参考骨架和单独烘焙的网格，在 **Input Video** 场景提供同步视频。请一起移动 `.blend`、`surface.pc2` 和 `video.mp4`。导出包含已应用的修正，编辑骨架时烘焙网格保持原样。角色 FBX 或 VMD 需先重定向到支持的角色。详见 [GEM-X 中文指南](models/GEMX.zh-CN.md)。

### MAMMA 完整场景 Blender 工程

选择 Blender 格式后，勾选 MAMMA 完整场景选项，可将勾选的人物、可见动作片段、全部已校准相机及同步视频导出到同一工程。该模式保留原时间轴。人物表面以 PC2 缓存烘焙，参考骨架可独立编辑。移动工程时，请把 `.blend`、`videos/` 和 `meshes/` 一起移动。使用条件见[英文指南](USER_GUIDE.md#mamma-whole-scene-blender-projects)。
